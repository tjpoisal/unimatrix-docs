## Boilerplate

Unimatrix is a shared persistent memory layer for supported AI assistants, agents and applications. Connected clients explicitly save and recall decisions, sources and project context through MCP or REST, with other client surfaces offering their own setup paths. Source lineage and correction history help keep changing knowledge traceable.

The 2.0 TypeScript server architecture adds associative memory relationships and explicit graph activation recall. Code integration, hosted availability and real-client validation are separate milestones. A Rust reference engine and hardware research do not imply that the managed service runs on those components.

Memory content uses AES-256-GCM encryption at rest. Processing may require plaintext and searchable derived data remains access-controlled. The service must not be described as universally zero-knowledge or end-to-end encrypted.
